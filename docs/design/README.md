# Svelto interface directions

Open `svelto-directions.html` in a browser. These are interactive design prototypes, not screenshots of the implemented Electron app.

- **Quiet:** the closest evolution of Min. Horizontal tabs, a compact toolbar, restrained Mac details.
- **Inset:** more breathing room and an inset page surface, retaining tabs and tasks.
- **Focus:** an expanded active tab and search surface, retaining the same navigation model.

All visible product copy is English. The prototypes support light/dark appearance, tab selection, adding tabs, and task menus. Each direction was checked at desktop and narrow widths; these widths demonstrate layout resilience, not a planned mobile browser.

Selected direction: **Quiet**, confirmed by the project owner. Use it as the reference for browser chrome implementation while preserving Min’s horizontal tabs and tasks. Logo and production icons remain a separate milestone.

Quiet now drives the macOS toolbar in the Electron preview: a 52 px strip, 32 px tabs, 8 px corners, system typography, restrained light/dark colors and a layers-shaped Tasks control. Address editing remains inside the active tab. Native traffic lights and functional status icons are retained; production branding/icons are still pending. Narrow windows scroll the tab strip rather than wrapping browser chrome.

Mac keyboard flow: F6 or Shift+F6 toggles focus between the page and toolbar. Left/Right and Home/End select tabs while keeping toolbar focus; Enter/Space edits the focused active tab. Tab reaches its Close button, New Tab and Tasks; Enter opens Tasks and Escape returns to browsing. Cmd+L/T/W, Cmd+Shift+T, Ctrl+Tab and Cmd+9 retain their existing browser actions.

Quiet Preferences extends the selected palette into a centered 880 px document with a 28 px title, 19 px section headings, 14 px controls, 6 px input corners and thin section separators. Eight anchor links retain the original section order; narrow windows wrap navigation and stack shortcut/command fields. Controls keep their existing settings keys and localization. Custom user-agent fields use semantic hidden state, and generated command fields have accessible names.

Visual comparison with the generated Preferences concept checks five points: open single-column layout; title/section/body hierarchy; neutral surface and green accent; thin dividers/native controls; wrapping navigation and fields. The implementation intentionally retains the original localized copy, actual saved selections and exceptions below the selected blocking level rather than adopting the concept's shortened text or example state. The language field is stacked consistently with the other selects. Both light/dark renders and all eight sections were inspected in the packaged Electron app; VoiceOver coverage remains a separate audit.

Quiet Tasks keeps the original full-window grouped list, editable names, collapsible tasks, tab transfer targets and bottom New Task action. It reuses the existing Quiet palette, 880 px content width, system typography, 8/6 px control/row corners and thin separators; current task names and tab edges use the accent. At narrow widths, secondary URLs yield to readable tab titles. Search includes a live match/empty status and retains its filter across synchronized list updates. The hidden overlay is inert; names save on input, including paste; pending deletion can be undone with Enter/Space. No new workspace model is introduced.

Quiet search keeps address editing inside the active tab and Min's full-width plugin panel. Results use 13 px system text, 40 px minimum rows, 6 px corners, restrained icons and an accent edge/outline for keyboard selection. Narrow windows stack secondary URLs; rich descriptions, calculator actions, bookmark editing and shortcuts retain their existing structure. The address field has a localized name and exposes its suggestion dialog and expanded state. Remote and local history replies must still match the open query; failed suggestion requests clear their own results without interrupting navigation. IME confirmation does not submit an address. Full VoiceOver coverage remains pending.

Quiet collections retain the existing `!history` / `!bookmarks` flows and date groups. A 17 px heading and live result/empty status sit above 13 px rows. Clear History, row removal and bookmark editing have keyboard targets and accessible names; bookmarked history removal explicitly names both effects, preserving Min's original behavior. Tags wrap with 6 px corners, and the editor uses a bordered active surface with a labeled tag field. Instance-scoped edits persist before closing; duplicate/blank tags are ignored, spaces become hyphens, and removing a bookmark preserves the historical entry. Late replies cannot replace another query or revive a closed editor.

The Quiet download shelf stays 40 px tall, matching the existing page margin. Compact file buttons show title/status, a restrained progress line, direct Cancel or Show in Finder, and visible keyboard focus. Unknown sizes use indeterminate progress without invalid numeric values. File-open failures retain the item and allow retry; the auto-hide timer preserves that error. Local HTTP downloads verify completion, native cancellation and unknown-size progress. Shell open/retry and Finder dispatch are tested with controlled stubs rather than launching external apps. Original import/export, bulk history clearing, native file dragging and broader VoiceOver coverage need separate verification.
